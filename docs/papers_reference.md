## 📚 经典理论论文

### **1. Wagner冲击理论 (Water Impact Theory)**

**理论背景**: 扁平物体入水冲击的经典理论，描述接触线附近的压力分布和空腔形成。

**关键论文**:
1. **Wagner, H. (1932)** - 原始论文  
   - **标题**: "Über Stoß- und Gleitvorgänge an der Oberfläche von Flüssigkeiten"  
   - **英文翻译**: "On impact and gliding processes on the surface of liquids"  
   - **期刊**: Zeitschrift für angewandte Mathematik und Mechanik  
   - **DOI**: 10.1002/zamm.19320120402  
   - **状态**: 经典论文，可能受版权保护

2. **后续发展**:
   - **Korobkin, A.A. (1996)** - "Water impact problems in ship hydrodynamics"  
   - **Oliver, J.M. (2007)** - "Water entry and related problems"  
   - **Truscott, T.T. et al. (2014)** - "Water entry of projectiles"

### **2. Rayleigh空腔坍缩理论 (Cavity Collapse Theory)**

**理论背景**: 球形空腔在静水压力下坍缩的经典分析，为射流形成提供理论基础。

**关键论文**:
1. **Rayleigh, Lord (1917)** - 原始论文  
   - **标题**: "On the pressure developed in a liquid during the collapse of a spherical cavity"  
   - **期刊**: Philosophical Magazine  
   - **DOI**: 10.1080/14786440808635681  
   - **状态**: 经典论文，已进入公共领域

2. **后续发展**:
   - **Plesset, M.S. (1949)** - "The dynamics of cavitation bubbles"  
   - **Brennen, C.E. (1995)** - "Cavitation and bubble dynamics"

### **3. Worthington射流理论 (Worthington Jet Theory)**

**理论背景**: 液滴冲击固体表面形成射流的实验观察和理论分析。

**关键论文**:
1. **Worthington, A.M. (1908)** - 原始著作  
   - **标题**: "A Study of Splashes"  
   - **出版社**: Longmans, Green and Co.  
   - **状态**: 经典著作，可能已数字化

2. **现代研究**:
   - **Thoroddsen, S.T. et al. (2008)** - "The Worthington jet revisited"  
   - **Gekle, S. et al. (2009)** - "High-speed jet formation after solid object impact"

### **4. Besant-Rayleigh缩放 (Besant-Rayleigh Scaling)**

**理论背景**: 球形空腔收缩的标度律，用于分析空腔坍缩的时间尺度和能量尺度。

**关键论文**:
1. **Besant, W.H. (1859)** - 原始问题  
   - **标题**: "A problem in the motion of a sphere in a fluid"  
   - **备注**: Rayleigh在1917年的论文中引用并发展了此理论

## 🛠️ 下载脚本

创建 `scripts/download_papers.py` 脚本来自动化下载过程：

```python
#!/usr/bin/env python3
"""
论文下载脚本 - 尝试下载参考文献中列出的论文
"""

import requests
import os

PAPERS_DIR = "papers"

# 论文URL列表（需要补充具体链接）
paper_urls = [
    # 示例：arXiv论文
    # ("Impacting_spheres_2025.pdf", "https://arxiv.org/pdf/2510.xxxxx.pdf"),
]

def download_paper(filename, url):
    """下载论文PDF"""
    try:
        response = requests.get(url, timeout=30)
        if response.status_code == 200:
            path = os.path.join(PAPERS_DIR, filename)
            with open(path, 'wb') as f:
                f.write(response.content)
            print(f"✅ 下载成功: {filename}")
            return True
        else:
            print(f"❌ 下载失败 {url}: HTTP {response.status_code}")
            return False
    except Exception as e:
        print(f"❌ 下载失败 {url}: {e}")
        return False

if __name__ == "__main__":
    os.makedirs(PAPERS_DIR, exist_ok=True)
    
    for filename, url in paper_urls:
        download_paper(filename, url)
```
